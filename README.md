# 📊 Order-to-Cash (O2C) Operations & Performance Dashboard

## 🚀 Project Overview
This project presents an end-to-end **Order-to-Cash (O2C) Operations Dashboard** built using **Power BI**. The objective is to analyze key financial and operational metrics such as Revenue, Days Sales Outstanding (DSO), Order Processing Status, Aging Buckets, and Service Level Agreements (SLA) to help businesses optimize cash flow and order fulfillment efficiency.

---

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** For data modeling, DAX measures, and interactive data visualization.
* **Dataset:** O2C performance transactions dataset (`o2c_performance_dataset.csv`).
* **GitHub:** For version control and project documentation.

---

## 📈 Key Metrics & Visuals Included
1. **KPI Cards:** 
   - Total Revenue / Invoice Amount
   - Average Days Sales Outstanding (Avg DSO)
   - Total Orders Count
   - SLA Compliance Tracking
2. **AR Aging Bar Chart:** Analyzes outstanding invoice amounts across different aging buckets (`0-30 Days`, `31-60 Days`, etc.).
3. **Order Process Status Donut Chart:** Breaks down orders by fulfillment stages (Completed, On-Hold, etc.).
4. **Customer & Region Performance Matrix Table:** Detailed breakdown of customers, regions, invoice amounts, and individual SLA statuses.

---

## 💡 Key Business Insights
* Identifies customers and regions contributing to higher DSO and delayed payments.
* Tracks operational bottlenecks in order processing to improve cash conversion cycles.
